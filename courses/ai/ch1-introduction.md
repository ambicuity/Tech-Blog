# Chapter 1: Introduction to AI

> **Reference**: *Artificial Intelligence: A Modern Approach* by Russell & Norvig, Chapter 1

We define AI not by "simulating a human", but by **Rationality**.

## 1.1 What is AI?
Four Definitions:
1.  **Thinking Humanly**: Cognitive modeling.
2.  **Acting Humanly**: The Turing Test approach.
3.  **Thinking Rationally**: Logic. "Socrates is a man...".
4.  **Acting Rationally**: The **Rational Agent** approach. (This book's focus).

### Rational Agent
An agent is something that acts. A **rational agent** is one that acts so as to achieve the best outcome or, when there is uncertainty, the best expected outcome.

## 1.2 Foundations
AI draws from:
- **Philosophy**: Can formal rules draw valid conclusions? (Logic).
- **Mathematics**: Computability, Logic, Probability.
- **Economics**: Decision theory (Maximizing utility).
- **Neuroscience**: How do brains process information?
- **Control Theory**: Homeostasis, Stability.

## 1.3 History of AI
- **1956**: "Artificial Intelligence" coined at Dartmouth workshop.
- **1952-1969**: Great Expectations. Checkers player, LISP.
- **1974-1980**: First AI Winter. (Underestimated complexity).
- **1980-1988**: Expert Systems boom.
- **1987-1993**: Second AI Winter. (Lisp machines failed).
- **1995-Present**: The Agent view. Probabilistic reasoning.
- **2012-Present**: Deep Learning revolution.
