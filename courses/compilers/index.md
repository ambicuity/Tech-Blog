# Compilers

> **Core Text**: *Compilers: Principles, Techniques, and Tools* (The Dragon Book) by Alfred V. Aho, Monica S. Lam, Ravi Sethi, and Jeffrey D. Ullman.

This course teaches how programming languages are translated into executable machine code.
