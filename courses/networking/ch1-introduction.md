# Chapter 1: Introduction to Computer Networks

> **Reference**: *Computer Networks* by Andrew S. Tanenbaum, Chapter 1

A **network** is a set of devices (often referred to as nodes) connected by communication links. A node can be a computer, printer, or any other device capable of sending and/or receiving data generated by other nodes on the network.

## 1.1 Uses of Computer Networks
- **Business**: Resource sharing (printers, cloud storage), Communication (email, VoIP), E-commerce.
- **Home**: Access to remote information (WWW), Personal communication, Entertainment (Netflix, Gaming).
- **Mobile**: Portable office, Location-based services, m-commerce.

## 1.2 Reference Models

### The OSI Reference Model (7 Layers)
"**P**lease **D**o **N**ot **T**hrow **S**ausage **P**izza **A**way"

1.  **Physical Layer**: Transmission of raw bits over a communication channel. converting 1s and 0s to electrical/optical signals.
2.  **Data Link Layer**: Node-to-node data transfer. Handles framing and error detection. (Ethernet, WiFi).
3.  **Network Layer**: Routing packets from source to destination across multiple networks. (IP).
4.  **Transport Layer**: End-to-end communication and reliability. (TCP, UDP).
5.  **Session Layer**: Dialog control (mostly deprecated/handled by App layer now).
6.  **Presentation Layer**: Syntax and semantics of information (Encryption, Compression).
7.  **Application Layer**: User interface and network services (HTTP, SMTP, FTP).

### The TCP/IP Model (4 Layers)
The practical model used by the Internet.
1.  **Link Layer** (OSI 1 & 2)
2.  **Internet Layer** (OSI 3) - IP, ICMP
3.  **Transport Layer** (OSI 4) - TCP, UDP
4.  **Application Layer** (OSI 5, 6, 7) - HTTP, DNS, SSH

## 1.3 Key Terminology
- **Bandwidth**: The maximum rate of data transfer across a given path.
- **Throughput**: The actual rate of data transfer achieved.
- **Latency**: The time it takes for a message to travel from source to destination.
    - $Latency = Propagation + Transmit + Queue + Processing$
- **Jitter**: The variation in packet delay.

## 1.4 Network Topologies
- **Bus**: All nodes connect to a single backbone cable.
- **Star**: All nodes connect to a central hub/switch. (Most common in LANs).
- **Ring**: Tokens pass around a ring of nodes.
- **Mesh**: Full or partial point-to-point connections. (High redundancy).
