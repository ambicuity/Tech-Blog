# Data Structures & Algorithms (DSA)

> **Core Text**: *Introduction to Algorithms* (CLRS) by Cormen, Leiserson, Rivest, and Stein.

This course covers the mathematical foundations of algorithms, advanced data structures, and analysis techniques necessary for solving complex computational problems.

- [**Chapter 4: Divide-and-Conquer**](/courses/dsa/ch4-divide-and-conquer/)
